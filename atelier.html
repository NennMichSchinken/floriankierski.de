6Server2024–2026

My own Linux serverMein eigener Linux-Server

To learn the system side, I set up and ran a Linux server myself. Today it's switched off, hence the dark lights. Um die Systemseite zu lernen, habe ich selbst einen Linux-Server aufgesetzt und betrieben. Heute ist er aus, darum die dunklen Lämpchen.

To learn the system side, I set up and ran a Linux server myself, following the official documentation: a game server panel on my own domain, connected via DNS and secured with HTTPS. When an expired certificate took it down, I found the cause in the logs, with help from the community. Um die Systemseite zu lernen, habe ich selbst einen Linux-Server aufgesetzt und betrieben, nach der offiziellen Dokumentation: ein Gameserver-Panel auf meiner eigenen Domain, per DNS angebunden und mit HTTPS abgesichert. Als ein abgelaufenes Zertifikat ihn lahmlegte, habe ich die Ursache in den Logs gefunden, mit Hilfe der Community.

Today it's switched off, hence the dark lights. What I learned stays. Heute ist er aus, darum die dunklen Lämpchen. Was ich gelernt habe, bleibt.
