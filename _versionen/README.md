# Versionen

Schnappschüsse der Seite. Nur zum Nachschlagen und Zurückholen —
**nicht auf den Server kopieren** (im `rsync`-Befehl ausgeschlossen).

| Ordner | Stand | Was drin ist |
|---|---|---|
| `v1_2026-08-18_nacht/` | 18.08.2026 | Erste fertige Fassung: Nachtszene, Pixel- und Klartext-Modus. Die Version, die vorzeigbar ist. |

Zu jedem Ordner liegt eine gleichnamige `.zip` daneben — die ist zum Verschicken
oder Archivieren gedacht, der Ordner zum Vergleichen.

## Zurückholen

Aus dem Projekt-Hauptordner heraus, überschreibt den aktuellen Stand:

```bash
cp -r _versionen/v1_2026-08-18_nacht/. ./
```

Vorher lohnt es sich, den aktuellen Stand ebenfalls als neuen Ordner hier
abzulegen — sonst ist er weg.
