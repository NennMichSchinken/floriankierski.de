# floriankierski.de

Personal website of Florian Kierski, UX/UI designer and media designer on the way into IT:
a small voxel alley with my workshop, my tools HamMeter and WispUI, and my CV.

Live at https://floriankierski.de

This repository holds the built site as GitHub Pages serves it (static files, no build step here).
The 3D scenes are built in Blender by script and exported as GLB with baked light; the pages use three.js.

- `index.html`: the alley (start page); `atelier.html`, `wispui.html`, `null-meter-reise.html`, `devlog.html`,
  `impressum.html`, `datenschutz.html` open as a card over it
- `about/`, `hammeter/`, `wispui/`, `devlog/`, `impressum/`, `datenschutz/`: short addresses
- `js/`, `css/`, `modelle/` (GLB), `bilder/`, `lib/` (three.js), `schriften/` (fonts), `lebenslauf/` (CV as PDF)
